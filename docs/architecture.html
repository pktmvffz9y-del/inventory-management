1
User changes a filter
FilterBar.vue — Time Period, Warehouse, Category, or Order Status dropdown
2
Shared filter state updates
useFilters.js singleton composable — refs: selectedLocation, selectedPeriod, selectedCategory, selectedStatus
3
Page component watch() fires
Each view deep-watches getCurrentFilters() — maps selectedLocation → warehouse, selectedPeriod → month
4
API call dispatched
api.js builds URLSearchParams → GET /api/orders?warehouse=Tokyo&category=sensors&month=2025-01
5
FastAPI endpoint receives request
main.py extracts query params → calls apply_filters(orders, warehouse, category, status)
6
In-memory filtering
apply_filters() case-insensitive match, 'all' bypasses. filter_by_month() handles 2025-01 and Q1-2025 quarter formats
7
Pydantic serializes response
Filtered Python dicts validated against Order Pydantic model → JSON array returned to browser
8
Vue re-renders
Component updates reactive ref → computed properties recalculate → DOM updates automatically
